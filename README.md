# Fictional Student Dataset

Assignment Two: a fictional dataset of 200 students, generated with Python.

## Columns
| Column | Description |
|---|---|
| Student ID | Unique ID (e.g. STU2025CSC0001) |
| Department | Student's department |
| Level | 100, 200, 300, 400 or 500 |
| Attendance Percentage | 40 to 100 |
| Average Examination Score | 0 to 100 |

## How to run
```
python generate_dataset.py
```
This creates `students.csv`. All data is fictional.
